## Implementation rule

The homepage file is the approved visual starting point, not inspiration.

For Profile Studio, preserve the two-column composition and styling before
integrating real Svelte components. The production implementation should use
the existing shared profile renderer and current draft/publish contracts.

Do not add decorative orbs, abstract blobs, generic gradients, dashboard
statistics, extra panels, or filler copy to "complete" either reference.
