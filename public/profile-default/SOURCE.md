# Default profile background

`starfield-blue.webp` is a project-owned raster generated for the focused
Signal default profile. It is a quiet deep-blue nebula texture with a dark
center, sparse blue/lavender stars, and no embedded interface, text, avatar,
or border. The renderer uses it only when a profile still has the untouched
Signal defaults; user-uploaded backgrounds and authored atmospheres take
precedence.

Generation brief: “Create one seamless wide website background image, no
interface, no card, no avatar, no text; deep navy-blue celestial night texture
with subtle cloudy nebula wisps, sparse tiny blue/lavender stars, gentle
vignette, low contrast behind white profile text, and a darker calm center; no
stripes, geometric dot pattern, bright objects, planets, border, or watermark.”
