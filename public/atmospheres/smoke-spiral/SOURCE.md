# Smoke Spiral source

Source clip: [Spiral Smoke Effect on Dark Background](https://www.pexels.com/video/spiral-smoke-effect-on-dark-background-34818523/)
by Graham Thorne, accessed 2026-08-04.

The 16:9 source was converted to a soft grayscale smoke plate with the dark
backing retained for additive compositing. A 20-second forward-and-reverse
cycle preserves the sculptural motion while giving the browser a clean loop
boundary; the poster is a representative mid-loop frame.
