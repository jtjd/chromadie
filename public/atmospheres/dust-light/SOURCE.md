# Dustlight source

Source clip: [Close-up Abstract Dust Particles in Light Beam](https://www.pexels.com/video/close-up-abstract-dust-particles-in-light-beam-36637658/)
by Evgenij Mikhailov, accessed 2026-08-04.

The 16:9 source was reduced to a quiet monochrome light-beam plate and encoded
as a 12-second loop. A 1.2-second crossfade joins the end back to the start so
the video element's native loop never exposes a hard reset. The screen blend
retains only the authored particles and light; the poster is the reduced-motion
fallback.
