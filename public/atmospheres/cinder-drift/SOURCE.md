# Cinder Drift source

Source clip: [Dramatic Flying Sparks on Black Background](https://www.pexels.com/video/dramatic-flying-sparks-on-black-background-29936066/)
by Sini Ko, accessed 2026-08-04.

The 16:9 source was converted to a restrained grayscale spark plate with the
black backing preserved for screen blending. A 14-second forward-and-reverse
cycle keeps the native video loop from cutting between unrelated spark
positions; the poster is a representative mid-loop frame.
