# Silk Folds source

Source clip: [Top View of Black Fabric Texture](https://www.pexels.com/video/top-view-of-black-fabric-texture-7677746/)
by Mikhail Nilov, accessed 2026-08-04.

The vertical source was center-cropped into a 16:9 grayscale highlight plate.
Low-luminance fabric detail is suppressed so the moving folds remain additive
when screen-blended over a profile. A 9.4-second forward-and-reverse cycle
creates a clean loop boundary; the poster is a representative mid-loop frame.
