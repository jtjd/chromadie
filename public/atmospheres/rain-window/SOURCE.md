# Rain Window sources

Motion source: [Heavy Rain Falling on Black Background](https://www.pexels.com/video/heavy-rain-falling-on-black-background-36344044/)
by Zaheer Ahmad, accessed 2026-08-04. The creator describes this clip as a
seamless loop and tags it for overlays, so it is used as the local WebM/MP4
motion plate without a tail-to-head crossfade. The black backing is intended
for the profile atmosphere's screen blend.

Glass texture source: [Rain Droplets on Windshield Close-Up](https://www.pexels.com/video/rain-droplets-on-windshield-close-up-34479250/)
by Jonathan David, accessed 2026-08-04. One representative frame was
converted into a low-opacity, high-contrast droplet highlight plate and is
kept static so the irregular glass texture does not jump at the motion loop.

The unmodified source videos are not shipped; only the composed local plates
are included.
