# Rain Window source

Source clip: [Rain Droplets on Windshield Close-Up](https://www.pexels.com/video/rain-droplets-on-windshield-close-up-34479250/)
by Jonathan David, accessed 2026-08-04.

The source was cropped to 16:9, converted into a high-contrast droplet
highlight plate, trimmed to a 14-second loop with a one-second tail-to-head
crossfade, and encoded as local WebM/MP4 assets. The unmodified source video
is not shipped.
