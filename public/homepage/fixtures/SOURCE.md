# Homepage showcase fixtures

These local backgrounds and portraits are purpose-made showcase
assets for the approved homepage reference. They are deterministic homepage
fixtures only: they do not represent accounts, are not queried from the
database, and cannot enter discovery, leaderboards, or production profile
state.

## Katt / P2 media folder

`p2/p2avatar.png` is the user-provided portrait for the second homepage
specimen, displayed as `katt`. `p2/background-snowy-mountains.png` is a
generated snowy mountain landscape created for this fictional fixture, with a
quiet center for the transparent Framed profile card.

## Meilin

`meilin/background-dusk-v2.webp` and `meilin/avatar.webp` are dedicated,
purpose-made artwork for the first homepage profile specimen. The dusk
background uses the avatar as a palette reference and keeps the center quiet
for profile readability. The previous `meilin/background.webp` remains in the
repository as a fallback. These assets were generated for this fictional
profile and are not borrowed from profiles 2–4 or from production user media.
