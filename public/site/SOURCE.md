# Chromadie site atmosphere

`chromadie-roll-horizon.webp` is a locally stored generated presentation asset for normal Chromadie application pages.

It visualizes the product loop as a quiet horizon where daily roll colors accumulate into a personal world. The palette follows the authored homepage fixture colors—lavender, rose, azure, amber, and restrained emerald—while keeping lavender as the shared interface accent.

The image is intentionally static and content-safe. It does not replace profile backgrounds, public profile rendering, roll data, or any server-authoritative behavior.
