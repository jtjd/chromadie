# Pre-Commit Checklist

- [ ] Change belongs to active milestone.
- [ ] Product north star is clearly supported.
- [ ] No client-authoritative gameplay or entitlement logic added.
- [ ] Owner, visitor, guest, loading, empty, and error states considered.
- [ ] Mobile behavior verified.
- [ ] Reduced-motion behavior verified.
- [ ] No raw HTML, JS, or CSS customization introduced.
- [ ] No private data exposed.
- [ ] Tests added or updated.
- [ ] Documentation updated.
- [ ] Required validation commands pass.
