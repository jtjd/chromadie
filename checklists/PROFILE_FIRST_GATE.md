# Profile-First Gate — Phase 10

This is the acceptance checklist for the Phase 10 profile reconciliation.

- [x] Authenticated bare root resolves to the owner’s live profile.
- [x] Explicit authenticated roll navigation remains available.
- [x] Identity, roll/latest result, expression, and one featured surface are
      the only primary regions.
- [x] Public-boundary/developer explanation is absent from the default public
      hierarchy.
- [x] Stats, history, collections, achievements, social, configuration, and
      account controls are preserved behind detail or compatibility surfaces.
- [x] Real mapped production data is used by the live composition.
- [x] Public routes, direct refresh, old share links, and `legacy=1` remain
      intact.
- [x] Desktop screenshots are captured at 1440×900 and 1280×720.
- [x] Mobile screenshot is captured at 390×844 with identity and roll first.
- [x] Primary composition bottom is within both desktop viewport heights.
- [x] Keyboard and reduced-motion contracts remain covered.
- [x] No schema, authentication, RLS, roll, scoring, reward, economy,
      entitlement, social, moderation, or deployment behavior changed.
- [x] Required tests and validation results are recorded in
      [`docs/PHASE_10_REPORT.md`](../docs/PHASE_10_REPORT.md).
- [x] Phase 11 remained outside the Phase 10 scope and is tracked separately
      in its own milestone/report.
