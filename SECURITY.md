# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting for this repository. Open the repository's **Security** tab, choose
**Advisories**, then select **Report a vulnerability**. Include the affected
area, steps to reproduce, and the impact you observed. Do not put credentials,
personal data, or exploit details in a public issue.

Reports are reviewed by the repository maintainers. Please allow time for
triage and coordinated remediation before public disclosure.

## Supported versions

The current `main` branch and the latest production release are supported for
security fixes. Older commits and unreleased branches are not maintained.
